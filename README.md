# 🐍 Словозмей

Змейка, которая ест буквы и собирает из них слова. Работает на телефоне и компьютере, ставится как приложение, играть можно без интернета.

**Как играть.** Сверху показано слово. Веди змею и ешь его буквы по порядку. Неверная буква или столкновение с собой отнимает жизнь (всего три). Края поля проходные. Чем больше слов подряд без ошибок, тем больше очков.

**Управление.** Свайп по полю или стрелки / WASD. Пауза: пробел или кнопка внизу.

**Языки.** Русский, украинский, английский.

## Установка на телефон
- **iPhone (Safari):** кнопка «Поделиться», потом «На экран Домой».
- **Android (Chrome):** меню ⋮, потом «Установить приложение».

## Разработка
Проверка логики: `node tests/core.test.js`. Игра: открыть `index.html` через любой статический сервер.

Файлы: `core.js` (правила игры без экрана), `app.js` (рисование, управление, звук), `style.css`, `sw.js` (офлайн).
